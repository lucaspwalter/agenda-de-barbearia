# Barbershop Scheduler

Platform for clients, barbers, services, appointments, waiting lists and notifications.

## Tech Stack

Node.js, TypeScript, Fastify, PostgreSQL, Knex and Next.js.

## Getting Started

```bash
git clone https://github.com/lucaspwalter/barbershop-scheduler.git
cd barbershop-scheduler
docker compose up
```

Open `http://localhost:3000`. WhatsApp integration requires an Evolution API instance.
